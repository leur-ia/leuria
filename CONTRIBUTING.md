# Contributing to Leuria

Thanks for helping. Start with:

- [Architecture](docs/contributing/architecture.md): how the engine and the SDK fit together.
- [Development](docs/contributing/development.md): setup, tests, and running with a real agent.

Before opening a pull request, run `pnpm check && pnpm test && pnpm build`, and update the docs your change touches. Report security issues privately, not in public issues.
